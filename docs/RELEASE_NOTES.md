## v2.0.0 候选（未发布）

- 桥接插件提供 DSH 原生组合包；`qbf-cli bridge` 独立管理核验下载、安装、更新、回滚、移除与原操作核对。运行依赖归 DSH 管理，框架旧程序清理不再成为插件来源。

这是安装与恢复语义的主版本迁移。现有配置、会话与 SDK/线协议继续读取；旧手工 Loader 行或链接须显式迁移，详见 [安装生命周期](INSTALLATION_LIFECYCLE.md)。尚未发布或部署候选，测试范围见 [验收记录](VALIDATION.md)。

## v1.13.5

- 停止阶段失败时，按启动顺序尝试恢复本次已确认停止且属于启动范围的组件；停止未确认的组件不重复启动。启动阶段某项失败时继续尝试其余组件，原始失败与非零退出码保留。
- 一键恢复聊天为独立守护进程提供最多 60 秒冷启动登记时间，正常服务启动与统一就绪核验最多等待四分钟，对应阶段调用等待同步调整。
- 增加独立期限、部分失败恢复及真实受管进程停止与重新启动的回归验证，保留显式停止和外部进程的管理边界。

框架、SDK 与 DSH 桥接插件统一为 `1.13.5`。本批修复保持 `1.13.4` 的公开配置、SDK、线协议和持久数据兼容，已有会话无需迁移；显式停止仍保持停止，未知执行与发送不自动重放。升级沿用 [更新流程](UPDATING.md)，重启及恢复条件见 [服务运维](SERVICE_MANAGER.md)与[恢复手册](RECOVERY.md)。

## v1.13.4

- 助手只申报 `path` 与可选 `filename`，兼容旧 `kind`；受信文件系统宿主自动绑定账号、工作、会话和代次，统一签发 opaque 编号并执行全量流式 SHA256 与路径安全检查。
- 聊天发送按编号重新验归属并解析：共享文件系统使用原路径，跨机提供一次性真实 HTTP 流。小文件和 100 MiB 以上文件均不复制进附件库，不受原字节通道 8 MiB 判断阻塞；新登记不增加固定 TTL 或容量阈值，确认送达后撤销登记并保留原文件。
- 废弃助手→聊天的字节保存、Base64 回传与回退。旧字节入口明确返回失效／迁移错误，旧持久记录保留可读；删除、篡改、越界、符号链接逃逸和跨会话借用明确拒绝，未知发送不重放。

框架、SDK 与 DSH 桥接插件统一为 `1.13.4`，按维护者明确的补丁迁移约定交付。需要配套升级，自定义字节附件生产者需迁移到路径登记，旧字节接口行为不再兼容；其余配置、会话及 SDK 能力保持原兼容范围。原产物在回执确认前保持不变。远程协议端需要能够读取 DSH 专用流 URL，真实支持范围、安全边界与回滚要求见 [助手附件](WORK_ATTACHMENTS.md)。聊天 120000ms 期限、16384 输出预算与模型协议配置不变。

## v1.11.0 · DSH 事件衔接与有界传输

框架、SDK 与内置 DSH 桥接组件统一为 `1.11.0`。新增接口保持旧配置与会话可读；升级保留原 sessionId、QQ 登录、历史与执行／发送证据。

- 新事件订阅首帧只传身份与游标，修复长历史快照超过接收上限导致单会话持续无法提交的问题。主聊天与插件模型共用订阅实现，桥保存完成处理的位置，重连补读缺失执行观察；旧正文、模型请求和工具不会重放。
- 实时大事件按带长度与 SHA-256 的有界分块传输；每会话队列和共享接收内存均有字节预算。工具轮询按字节分页，并用完整待办编号核验撤销，避免分页误取消其他工具。
- 监听准备失败明确记为尚未提交模型，网络、包超限、协议与游标冲突分别诊断。会话之间并发建立监听，单会话握手不占用全局准入锁；确定性故障等待修复后明确重连。
- 会话诊断按目标会话查询，补齐最近监听故障；长会话执行核对逐记录计算检查点，并使用有界派生索引，移除整段日志序列化的 16 MiB 容量门槛。
- 内置组件按协议与能力协商兼容，构建版本仅用于诊断，移除逐版本白名单。SDK 数据源、事件服务、传输及游标存储通过接口分层；DSH 日志、上下文压缩和模型请求不因监听重构改变。
- 令牌鉴权为独立监听分配独立连接身份，修复多监听与立即重连的连接占用冲突；后续重连重新核对桥接组件加载代次。空间发布等待与外层工具预算同步延长。

完整包包含同版 SDK 与桥接组件附件。独立 DSH 需要加载配套组件后才能使用新事件接口；未声明该能力时保留最小历史页兼容路径，不将其显示为可恢复订阅。接口传输上限与恢复范围见 [DSH 接入](DSH.md) 和 [公共契约](CONTRACTS.md#dsh-事件接入)。

## v1.10.0 · 内置 HTML 图片与后台排版

框架、TypeScript SDK 与 DSH 桥接插件统一为 `1.10.0`。本次新增能力保持旧配置、会话与线协议兼容，并合并此前未发布的聊天及恢复修复；v1.9.2 候选不单独交付。

- 内置 `qbf_render_html`：静态 HTML/CSS 转 PNG 并发送到当前 QQ 会话，支持中文、彩色布局、Flex/Grid、表格与 SVG 路径。原生 CPU 组件随完整安装包内嵌，支持 Linux x64／ARM64 和 Windows x64，安装无需 Rust。脚本、外部网络和文件资源不加载。
- HTML 与 Markdown 通过持久后台队列排版发送，受理后主会话继续聊天，原模型轮次结束和后续消息不取消已受理图片。服务恢复可重做纯排版，发送结果未知不自动重发；发送前复核权限和绑定。
- Markdown 按实际像素、输出大小和渲染时间限制资源，完整内容生成一张长图，补齐数学与符号字体；取消独立公式条数硬限制。模型输出预算采用所选模型能力中的最大输出值，避免固定低预算截断。
- 原生组件按封装源码、锁文件和固定工具链指纹复用，框架升级无需重复 Rust 编译；缓存失效可从正式 Release 附件取回同组件。构建源码、Cargo.lock、Actions 与 [构建教程](HTML_BUILD.md) 一并保留在仓库。
- 群聊忙碌时待发消息合并，下一批实际提交才开始单轮期限；明确呼叫原文、真实发言者和时间随延期保留，在有界输入中优先于普通背景。新有效 @ 刷新续聊窗口，普通消息和重复回调不刷新；延期后的下一批不再被持续发言反复阻止发送。
- 自动补读在进入模型前过滤过期普通未读，默认15分钟，可在概览或人设续聊策略中调整，保存后即时生效。当前消息、已受理待答和明确引用保留；普通引用定向提供所引消息，历史和会话继续保存。纯 @ 或戳戳没有有效未读时作为当前招呼处理。
- 引用曾因超时未读而跳过的目标时，按实际保留历史补充附近上下文，整轮最多16条并包含目标。已读或正常新引用保持定向读取；受理后记录跳过证据，真正装入输入后清除。邻接仅辅助理解引用，缺失或截断明确标记。
- 控制台提供独立于旧应用锁的“一键恢复聊天”：恢复受管本机 DSH、框架与依赖，应用已保存设置并核验实际运行和聊天链路。协议端始终排除，只提供连接诊断和恢复指引。当前统一恢复限可信 Linux 单账号部署，多账号与远程 DSH 明确说明条件。
- 修复管理路由增加后默认宿主无法启动的问题；恢复按管理监听、依赖启动、最终完整健康分阶段进行，避免健康检查与依赖形成循环等待。
- 修复流程使用独立持久记录，网页断线后继续读取同一操作；管理登录跨受控重启保留。独立守护在恢复进程意外退出后尝试恢复管理页面，失败显示原因并允许再次恢复，未知响应不重复启停；历史成功不覆盖新管理操作或当前异常。
- 压缩累计的纯配置补丁，避免 DSH 配置无限增长；自动核验重载后原会话的设置，证据充分时结束已被新配置替代的旧应用阻塞。未知业务执行、工具及消息送达记录不清空、不重放。
- 超时后核对外部结束可解除隔离，原超时状态和原因继续保留；连接卡片按内容自然排布，聊天诊断不再把旁边卡片撑高。

## v1.2.0 · 统一插件服务、热重载与空闲性能优化

发布于 2026-10-29。框架、TypeScript SDK 与 DSH 桥接插件包版本为 `1.2.0`。

### 插件服务与热重载

- 内置能力与插件能力统一使用版本化服务契约、依赖声明、发布与取得入口；登记包含服务用途、来源、方法及运行状态。
- 协议、模型、持久会话、日程、媒体、工具、扩展管理、用量和观察事件通过绑定插件身份的宿主客户端提供。服务取得不隐式授权，也不把服务目录全部注入模型工具。
- 提供稳定服务代理及可替换行为 handler。兼容实现可热重载，已开始的调用在原代排空；加载失败保留当前实现，契约或注册结构变化需完整应用。
- 热重载共享未变化的源码文本，并增加默认 64 MiB 去重源码预算；保留最多 64 代与旧任务的延迟导入语义。
- 提供完整 TypeScript SDK 示例及服务规范、生命周期、取消、幂等与恢复说明。

### 持久日程与插件接入

- 通用插件日程支持持久规则、发生记录、取消与长任务期限，供插件组合使用。
- 修复插件持久模型会话和原生图像输入通路，并补全模拟入口与按需工具目录的调用链。

### CPU 与内存

- 空闲工具通道改为有界等待，有工具入队立即唤醒；正在执行时保留短轮询取消检查，旧插件维持原行为。
- 空队列与空任务索引通过存储变更令牌避免重复扫描，仍检测其他连接写入；SQLite 返回值保持完整校验和深冻结，减少重复深拷贝。
- 本机 DSH 凭据每次仍核验安全路径、权限与文件变化，未变化时复用 cookie，系统时钟回拨后重新签发；只读 YAML 使用完整内容键的有界缓存。
- 日历纯计算采用有界缓存；空闲规则不再每秒写入进度，跨过计划发生点时立即持久保存，保留重启、回拨和未知记录语义。

### 安装与兼容

Release 提供 `qq-agent-framework-sdk-1.2.0.tgz`、`qq-agent-framework-dsh-bridge-plugin-1.2.0.tgz` 和 `SHA256SUMS`，源码由 GitHub 提供，不发布到 npm 注册表。Node.js 仍要求 `>=24.12.0`；DSH SDK / Cordis 仍为 `0.2.1-rc.2` / `4.0.5`。

框架继续兼容已识别的旧桥接插件；工具等待优化需要更新并加载新版 DSH 桥接插件。服务使用方需声明其提供包与服务依赖；参考 [服务规范](SERVICE_CONVENTIONS.md)、[热重载示例](../examples/reloadable-plugin/README.md) 与 [升级说明](OPERATIONS.md#升级与备份)。本版不清空会话、账本或插件日程，不改白名单与主人权限。

- 补全收藏表情添加、删除和备注修改，消息贴表情与移除、自身群名片修改、自主撤回自身消息。内置聊天方案增加按语境收藏和使用表情的指引。
- 日常互动沿用会话准入；账号和管理类敏感操作核验真实主人。可信插件通过宿主能力服务调用，按插件身份与调用方策略校验，不伪装成 QQ 主人消息。

### 插件模型与媒体服务

- 插件可通过 `runtime.models` 使用已配置供应商与模型，读取模型目录，选择思考强度，执行单次生成或使用具名持久会话。
- 提供插件会话创建及绑定服务。插件可建立自己的会话，也可明确绑定已有模型会话；生成结果返回插件，QQ 发送等操作通过宿主能力服务执行。
- 模型请求与插件生命周期、排队限制及持久执行记录关联；同一模型会话串行执行，结果未知时可核对原请求。
- 新增 `runtime.media.readImage`，插件可以读取当前会话中已登记图片的原始字节、类型和摘要，复用会话范围及有效期校验，减少重复建立媒体登记链路。

### 会话与账本变更

- 控制台增加 QQ 与插件会话管理，支持查询、新建、换绑、解绑及运行状态核对；未绑定的插件会话也有管理入口。

- 绑定固定指向实际 DSH 会话。QQ 换绑后，绑定原会话的插件继续使用原会话；解绑保留模型历史，不删除 DSH 会话。
- 使用绑定版本校验和共享会话队列处理并发变更；独立助手的工作子会话不接受 QQ 或插件共享绑定。
- 账本增加插件来源标签与筛选，共享会话中的模型用量按实际请求及执行轮次归属，便于区分 QQ 聊天和插件调用。

### 控制台与维护

- 低频接口按用途聚合为能力包，在侧栏中搜索、浏览工具及参数说明。

# 助手结果附件

助手在已获准的独立工作子会话中调用 `qbf_work_attach({path, kind?})`，完成工作后由宿主通过原 QQ 会话的 outbox 投递。返回 `registered: true, sent: false` 只表示登记成功；实际上传回执决定送达状态。每次工作最多三个不同附件，文字中的本机路径不会自动变成附件。

## 共享文件系统的路径登记

配套宿主与桥接插件通过 `verifyWork.pathAttachmentsSupported` 和受信任 `startWork.attachmentTransport: 'path-v1'` 协商。宿主 DSH 适配器对本机回环连接默认启用共享文件系统；通过端口转发、容器隔离或远程接入时，应在可信适配器装配中设置 `sharedWorkFilesystem: false`，使用字节传输。回环地址只是部署默认值，不能证明两个进程的挂载 namespace 相同。

启用路径传输后，小文件和大文件均优先登记现有普通文件。文件没有原字节通道的 8 MiB 限制，不进入 DSH 字节附件库，也不复制到宿主的 `work-assets/`。图片仍使用原 PNG、JPEG、WebP、GIF 验证，图片内容最多 8 MiB；较大的图片可明确作为文件发送。图片验证会有界读取内容，不保存重复的字节附件；普通文件只流式计算哈希，自动识别类型时额外读取文件头。

登记允许的目录由可信 DSH 装配的 `workingDirectory.defaultDirectory` 与 DSH home 提供：

- 部署工作目录下的 `workspace/`；当部署工作目录本身名为 `workspace` 时，使用该专用目录。
- 当前 DSH home 的 `sessions/`。

模型改变当前 cwd 不改变这些根目录。生产 cwd 为项目根时，应将产物写到 `workspace/<任务>/`。不开放 `/`、`/root`、项目根目录或任意进程 cwd；不从模型参数接收根目录。相对输入仍按实际助手 cwd 解析。目录之外的输入可由有权限的助手读取并明确写成受控产物，再登记该产物。未经协商的旧调用方保持原字节行为。

桥接层持久保存 opaque `work-path-ref-<摘要>` 与文件描述，工作 journal 只引用编号；owner RPC `readWorkPath` 仅接受工作地址、编号与媒体类别，不接受文件路径或根目录。宿主核对回包与原引用后，持久登记独立 `work-path-<摘要>`，记录账号、QQ 会话、workId、childId、parent session 和 generation。聊天模型和 outbox 只使用资源编号。宿主发送解析返回核验后的绝对路径，沿用现有 OneBot 文件上传或图片分支。

## 完整性、范围与有效期

每份描述记录绝对规范路径、白名单根目录、大小、mtime、ctime、dev、inode、根目录至父目录的 dev/inode、全量 SHA256、登记时间及 24 小时有效期。哈希采用 256 KiB 缓冲顺序读取全部内容，不采样、不惰性跳过；大文件增加磁盘读取量，内存不随文件大小增长。重复登记同一工作中的同一文件版本复用原编号与原有效期，不续期。

登记、DSH 解析、宿主接收与最终发送分别检查真实路径、普通文件类型、单硬链接、文件及父目录身份、大小、修改时间、内容哈希和期限。打开时使用 `O_NOFOLLOW`（平台支持时）与非阻塞只读，读取前后检查文件描述符、路径及父目录链；任何符号链接、越界、篡改、父目录交换或作用域变化都明确拒绝。路径验证失败不静默转字节读取；只有协商时不支持路径传输才选择原字节通道。原字节链仍保持单项 8 MiB、512 项及 128 MiB 总量限制。

TOCTOU 边界：宿主完成核验后，协议端仍会另行按绝对路径打开文件，二者之间没有共享文件描述符或锁。目录身份与全量哈希检测核验期间及此前的替换，不能阻止同权限进程在核验返回后、协议端读取前修改路径或内容。请在回执确认前保留产物并保持不变。框架和可信本机助手不构成对恶意同 UID 进程的沙箱；需要跨进程不可变快照时，应由独立存储/协议提供对应契约。本版不通过复制大型文件或修改协议端掩盖这一边界。

## 重启与清理

DSH 路径登记保存于 home 的 `storages/qbf-work-paths/`，最多 512 项，独立于字节库容量；宿主路径登记同样最多 512 项，使用持久 store TTL。重启读取既有描述和原有效期，不重新启动工作、不重放未知投递。旧 issuer epoch 不能调用新通道；核对既有工作时使用新通道身份，原 parent/child/work/generation 必须一致。

DSH 在加载后、每小时和登记前回收超期登记；宿主使用既有持久存储过期清理。清理只删除登记，不删除工作区或 DSH 会话里的原文件。字节附件保留原有独立回收规则。进程退出、工作结果未知或 outbox 结果未知时保留既有核对语义，不自动重试外部发送。
